# 숲속 보드 친구들

초등 저학년을 위한 Android 가족 게임 모음입니다. 바둑, 장기, 체스, 오목, 엄마용 `블록 퍼즐`, 순발력 게임 `숲속 두더지 팡!`을 제공합니다. 모든 게임과 설치한 AI는 오프라인으로 사용할 수 있습니다.

## 설치

1. [최신 릴리스](https://github.com/BrainyJongmin/forest-board-friends/releases/latest)에서 APK를 받습니다.
2. Android가 요청하면 다운로드에 사용한 브라우저 또는 파일 앱의 `출처를 알 수 없는 앱 설치`를 허용합니다.
3. APK를 열어 설치합니다. 업데이트도 같은 주소의 새 APK를 기존 앱 위에 설치하면 됩니다.

AI 코치 모델은 선택 사항입니다. 앱의 `AI 코치` 화면에서 Wi-Fi로 약 736MB를 한 번 받으면 이후 대화가 기기 안에서만 처리됩니다. 모델이 없어도 모든 게임과 기본 힌트는 작동합니다.

## 업데이트 확인

앱 홈의 `앱 정보` → `최신 버전 확인`을 누르면 [GitHub 최신 릴리스](https://github.com/BrainyJongmin/forest-board-friends/releases/latest)가 열립니다. 새 APK를 받아 기존 앱 위에 설치하면 이름과 기록을 유지하면서 업데이트할 수 있습니다.

## v1.0.11 변경 사항

- 채팅 입력창의 마이크로 한국어 음성을 받아 적고, 확인·수정 후 전송
- 기기 내 음성 인식 우선 사용, 지원되지 않는 경우 사용자가 온라인 인식을 선택
- 숲속 두더지 팡!: 3개 테마와 12레벨, 30초 도전, 황금·헬멧 두더지, 콤보·별·최고 기록
- 타격마다 망치·말랑한 캐릭터 움직임·별 파티클·미리 로딩한 효과음·짧은 진동을 함께 재생
- 소리 설정에 게임 진동 켜기/끄기 추가, 진동 없는 기기에서도 정상 플레이
- 테트리스 회전을 연속으로 눌러도 자동 낙하가 멈추지 않도록 수정
- 테트리스 일시정지 중 아래/한 번에 내리기 조작으로 블록이 고정되던 문제 수정

[검증 결과와 실물 기기 확인 항목](docs/TESTING-v1.0.11.md)

### 음성 입력

채팅 옆 마이크를 누르고 처음 요청하는 마이크 권한을 허용하세요. 말한 내용은 입력창에 추가되며 직접 전송하기 전에는 AI에게 전달하지 않습니다. 취소해도 기존 글은 유지됩니다. 음성 인식 자체는 AI 모델 설치와 별개이며, 자유로운 AI 답변에는 모델이 필요합니다. 기기 내 한국어 인식이 지원되지 않으면 온라인 인식을 선택하거나 키보드를 사용할 수 있습니다.

### 숲속 두더지 팡!

홈에서 게임을 선택하고 1단계부터 시작하세요. 30초 안에 표시된 목표만큼 잡으면 다음 레벨이 열립니다. 황금 두더지는 보너스 점수, 헬멧 두더지는 두 번 타격해야 합니다. 빈 구멍을 치거나 두더지를 놓치면 콤보가 끊깁니다. 스테이지 별·최고 점수·해금 기록은 기기에 저장됩니다. `소리 설정`에서 음악·효과음과 게임 진동을 조절할 수 있습니다. 회전 중 경기는 유지되며, 다른 앱으로 이동하면 일시정지됩니다.

## v1.0.10 변경 사항

- 태블릿 가로 화면에서 착수·무르기·힌트 뒤 보드와 체스 이동 영역이 늦게 갱신되던 문제 수정
- 보드 말을 놓는 타격음과 블록 퍼즐 줄 삭제 효과음을 짧은 PCM 효과음으로 교체
- 블록 퍼즐 아이템을 빗자루·거북이·별·폭죽·망치·가방 6종으로 확대
- 블록 퍼즐 레벨이 바뀔 때 `Korobeiniki`와 `Kalinka` 기반 자체 락 편곡을 번갈아 재생
- 보드게임 음악에 화음·아르페지오·베이스·드럼을 추가
- 설치한 온디바이스 AI가 최근 대화 문맥을 이어서 답하고 경기 중 가끔 직접 응원하도록 개선

## v1.0.9 변경 사항

- 아이템 발동 시 게임이 잠시 멈추고 동물 친구와 아이템 이름이 크게 나타나도록 개선
- 레벨이 오르면 빈 통로가 있는 바닥 도전 블록을 1~3줄 추가
- 설정에서 배경 음악과 효과음을 각각 끄거나 0~100%로 조절하고 기기에 저장
- 블록 퍼즐 음악을 러시아 민요 [`Korobeiniki`](https://www.museumofplay.org/games/tetris/) 선율에 드럼과 파워 코드가 들어간 자체 락 편곡으로 교체

## v1.0.8 변경 사항

- 블록 퍼즐의 예상 착지 위치 표시 제거
- 줄이 사라진 위치에 금빛 플래시와 컬러 파티클 효과, 전용 효과음 추가
- 블록 퍼즐 AI가 5조각마다 또는 줄 삭제 시 텍스트로 감탄하고 응원
- 블록 퍼즐에서만 더 빠른 템포와 강한 리듬의 전용 아케이드 음악 재생

## v1.0.7 변경 사항

- 모든 게임에 반복 재생되는 숲속 아케이드 배경 음악과 승패 시 박수 효과 추가
- 승리·패배에 맞춰 동물 친구들이 축하하거나 위로하고 `다시 하기`·`그만하기` 선택 제공
- 블록 퍼즐의 한 번 내리기와 회전 버튼 위치 교환, 다음 레벨 목표와 진행률 표시
- 블록 퍼즐에 노템전과 아이템전 추가: 다람쥐 빗자루, 거북이 시간, 별점수가 4줄마다 자동 발동
- AI 코치가 경기 중 먼저 응원하고, 3인칭 보고체 대신 아이에게 직접 말하는 대화체로 조정

아이템전은 [Puyo Puyo Tetris 2의 파티·스킬 배틀](https://puyo.sega.com/tetris2/)과 [공식 Tetris 모바일의 목표·부스터 방식](https://tetris.com/news/world-tetris-day-press-release-2024)을 참고해 어린이가 바로 이해할 수 있는 자동 아이템으로 단순화했습니다.

## v1.0.6 변경 사항

- 블록 퍼즐 좌우·아래 버튼을 누르는 즉시 움직이고, 길게 누르면 빠르고 일정하게 반복 이동
- 블록 착지 위치 미리보기와 움직이는 광택 효과 추가
- 체스 퀸을 포함한 합법 수 안내를 보강하고 보통 AI를 3수 탐색으로 강화
- 바둑의 따냄·자살수·패·두 번 연속 한 수 쉼 종국을 검증하고 AI의 축머리·단수·연결·집 지키기 판단 강화

## v1.0.5 변경 사항

- GitHub 최신 릴리스로 바로 이동하는 업데이트 확인 버튼 추가

## v1.0.4 변경 사항

- 체스 힌트 버튼의 앱 크래시 수정 및 2수 앞을 보는 추천 수 적용
- 오목의 즉시 승리·방어와 열린 3/4 판단, 바둑·장기 추천 수 보강
- 체스·장기 말을 선택하면 이동 가능한 위치 표시
- 장기 궁성 안 차·포 대각선 이동, 반복/무르기와 외통 판정 보강
- 장기말을 실제 표기(`楚/卒`, `漢/兵`)와 초서체/해서체로 표현
- 승패 후 숲속 친구 애니메이션과 `다시 하기`·`홈으로` 제공
- 태블릿 가로 화면에서 보드와 조작 패널을 좌우 배치하고 회전 중 게임 유지
- 게임 중 뒤로가기 확인 문구를 `홈으로`·`계속하기`로 변경

## 개발 빌드

JDK 17과 Android SDK 37이 필요합니다.

```powershell
./gradlew.bat test lint assembleDebug
```

릴리스 서명에는 `ANDROID_KEYSTORE_PATH`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`, `ANDROID_KEY_PASSWORD` 환경 변수를 사용합니다.
처음 생성한 `signing` 폴더는 앱 업데이트에 계속 필요하므로 GitHub에 올리지 말고 안전한 개인 저장소에 백업하세요.

## 개인정보

이름, 게임 기록과 설치한 AI의 대화 처리는 기기에 남습니다. AI 대화 문맥은 실행 중 메모리에만 유지하며 대화·녹음 파일은 저장하지 않습니다. 모델 다운로드에는 인터넷을 사용합니다. 음성 입력은 기기 내 인식을 우선 사용하지만, 사용자가 온라인 인식을 선택하면 음성이 기기의 음성 인식 서비스로 전송될 수 있습니다. 온라인 인식으로 자동 전환하지 않습니다.
