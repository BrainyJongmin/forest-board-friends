# v1.0.11 검증 기록

검증일: 2026-09-19

## 자동 검사

- `gradlew.bat testDebugUnitTest lintDebug assembleDebug assembleDebugAndroidTest`: 통과
- 단위 테스트 22개: 기존 보드게임, 블록 퍼즐 일시정지, 두더지 12단계 목표 달성·타격·콤보·시간 정지·오디오 데이터 검사
- Android 15 / API 35 가상 기기에서 UI 테스트 3개 통과
- 휴대폰 1080×1920 / 420dpi와 태블릿 1600×2560 / 240dpi에서 실행
- 연속 회전 중에도 테트리스 자동 낙하 진행
- 두더지 터치 시 점수 갱신, 일시정지 중 시간 보존, 가로 전환 후 점수 유지
- 채팅 마이크 표시와 인식 취소/서비스 실패 후 기존 입력 보존
- 두더지 세로·가로 화면 캡처로 배치 확인

연결된 테스트 기기에서 다시 실행하려면 `gradlew.bat connectedDebugAndroidTest`를 사용합니다. 테스트는 이름 입력이 필요한 경우 `테스트`를 입력하며 두더지 점수 등 해당 기기의 앱 데이터를 변경할 수 있으므로 별도의 테스트 기기를 권장합니다.

## 실물 기기 확인 필요

가상 기기는 실제 발화 인식률, 스피커 음질, 진동의 세기·느낌을 검증하지 못합니다.

1. 마이크 권한 허용/거부 모두 키보드 입력이 가능한지 확인합니다.
2. 한국어로 말한 문장이 초안에 들어가고, 전송 버튼을 눌러야 AI에게 전달되는지 확인합니다.
3. 기기 내 한국어 인식이 없으면 온라인 인식 안내에서 직접 선택해야 하며, 취소하면 외부 인식을 시작하지 않아야 합니다.
4. 녹음 중 배경 음악이 작아지고 코치 음성이 멈추는지, 취소·완료·앱 복귀 후 정상 볼륨인지 확인합니다.
5. 두더지 타격마다 짧은 진동이 오는지 확인합니다. 헬멧 첫 타격도 포함하며, 빈 구멍과 이미 잡은 두더지는 진동하지 않습니다.
6. 앱의 `소리 설정 → 게임 진동` 또는 기기 터치 진동을 끄면 진동하지 않아야 합니다. 진동 모터가 없는 태블릿도 플레이할 수 있습니다.
7. 황금·헬멧 두더지, 결과 화면, 다음 단계 해금과 앱 재실행 후 기록 보존을 확인합니다.

음성 인식 서비스와 한국어 모델의 지원 여부는 기기마다 다릅니다. AI 대화 모델 설치와 음성 인식 서비스 설치는 별개입니다.
